The real customer and bakery apps, running side by side. Place an order on the phone and watch it ring on the tablet.

  • Customer phoneUse any Iraqi mobile number, for example 0751 234 5678.
  • Bakery loginUse 0750 000 0001 for Furn Al-Noor or 0750 000 0002 for Duhok Golden.
  • WhatsApp codeNo message is sent here. The 6-digit code appears in the yellow box under the input.
  • Order soundTap anywhere on the tablet once to allow the new-order chime.

This preview uses a simulated server inside the page, with the same rules as the real API: 3 codes per hour per number, a 5-minute cancel window, and each bakery seeing only its own orders. Data resets when you reload. The production API, PostgreSQL database and WhatsApp delivery run once the project is deployed.
